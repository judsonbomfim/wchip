INFORMAÇÕES DE USO

Você adquiriu um eSIM da WorldChip. A instalação é rápida e simples — siga o passo a passo abaixo:


Antes de começar

  • Conecte-se a uma rede Wi-Fi
  • Ative os dados móveis
  • EXCLUA TODOS OS eSIMs DE VIAGENS ANTERIORES (OBRIGATÓRIO)
  • Realize a instalação somente na data de ativação informada no seu plano

• Realize a instalação somente na data de ativação informada no seu plano

Instalação do eSIM


iPhone

1. Acesse Ajustes

2. Toque em Celular

3. Toque em Adicionar eSIM

4. Selecione Usar código QR

5. Escaneie o QR Code

6. Siga as instruções na tela

7. Defina o eSIM WorldChip como principal para dados

8. Ative o Roaming de Dados


Android

1. Acesse Configurações

2. Toque em Conexões ou Rede e Internet

3. Acesse Gerenciador de SIM / eSIM

4. Toque em Adicionar eSIM

5. Escaneie o QR Code

6. Siga as instruções na tela

7. Defina o eSIM WorldChip como padrão para dados móveis

8. Ative o Roaming de Dados


Importante

  • O eSIM é vinculado ao aparelho no momento da instalação
  • O eSIM NÃO pode ser deletado após a instalação, pois não poderá ser utilizado novamente
  • Não será possível transferi-lo para outro dispositivo após ativação. Para qualquer necessidade, consulte nosso atendimento
